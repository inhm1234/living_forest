오늘의숲 애드센스 3차 심사 구조 분리 v3.1

핵심 변경
- / : 검색 가능한 공개 소개 콘텐츠만 유지
- /app.html : 로그인·내 정원·친구·QA·모달 등 운영 앱을 분리하고 noindex
- 기존 로그인 사용자가 / 를 열면 /app.html로 자동 이동
- 친구 초대·공유 기억·OAuth 콜백 주소도 /app.html로 전달
- 원오브텐과 QA 로그인에서 내 정원 복귀 주소를 app.html로 변경
- PWA 시작 주소를 app.html로 변경

업로드 후 주의
- 애드센스 검토 요청은 아직 누르지 않습니다.
- 먼저 공개 루트, 카카오 로그인, QA 로그인, 원오브텐 복귀를 실제 검증합니다.
